# Tier 1 Help Desk Homelab

## Overview
This project simulates a real-world Tier 1 help desk environment using VMware, Windows Server, Active Directory, Microsoft 365, and Spiceworks.

## Technologies Used
- Windows Server 2025
- Windows 11 Pro
- Active Directory
- Microsoft 365
- Spiceworks
- VMware Workstation Pro

## Lab Objectives
- Practice Tier 1 help desk workflows
- Troubleshoot common Windows and Microsoft 365 issues
- Simulate ticket resolution scenarios
- Improve documentation and support processes

## Environment
- DC01 (Domain Controller)
- HELPDESK01 (IT Admin Workstation)
- CLIENT01 (Standard User Workstation)
