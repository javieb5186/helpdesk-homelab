# VMware Lab Setup

## Environment
- VMware Workstation Pro
- Windows Server 2025
- Windows 11 Pro

## Virtual Machines
- DC01 (Domain Controller)
- HELPDESK01 (Tier 1 Workstation)
- CLIENT01 (Standard User Workstation)

## Networking
- NAT networking
- Static IP assigned to domain controller

## Purpose
This lab was created to simulate a small business Active Directory environment for Tier 1 help desk practice.
